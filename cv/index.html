Project 01

Brain Tumor Segmentation — MRI Deep Learning Pipeline

End-to-end deep learning system for automated brain tumor segmentation using the BraTS 2020 multimodal MRI dataset from 19 institutions — covering neuroimaging preprocessing through interactive inference.

  • Processed four MRI modalities (T1, T1ce, T2, FLAIR) as volumetric inputs, co-registered to a standard anatomical template at 1 mm³ resolution
  • Built and trained a U-Net convolutional architecture to segment three tumour sub-regions: GD-enhancing tumour (ET), peritumoral edema (ED), and necrotic/non-enhancing core (NCR/NET)
  • Defined custom evaluation metrics including Dice coefficient, precision, sensitivity, specificity, and per-class Dice scores
  • Implemented a custom DataGenerator with 5-fold train/validation/test splits and configurable callbacks for checkpointing
  • Deployed as a Streamlit web application accepting PNG, JPG and NIfTI files for real-time tumour probability inference

Project 05

Image Classification with Transfer Learning (CIFAR-10)

Computer vision classifier on the CIFAR-10 benchmark (10 classes, 60,000 images) using transfer learning with pre-trained ImageNet weights — achieving ~85% test accuracy.

  • Applied MobileNetV2 (ImageNet pre-trained) as a frozen feature extractor, adding a custom dense head (Dense 128 → Dropout 0.5 → Softmax 10) for classification
  • Pre-processed inputs via bilinear resizing (32×32 → 96×96) and MobileNetV2-specific normalisation
  • Trained for 30 epochs with Adam optimiser and categorical cross-entropy loss — Precision: 0.852, Recall: 0.852, F1: 0.852
  • Analysed results with confusion matrices and classification reports

Project 08

Soccer Tactical Feature Engineering (SkillCorner Broadcast Tracking)

Rich match-level tactical feature set engineered from SkillCorner broadcast tracking data (10 A-League 2024/25 matches), capturing structural and behavioural dimensions of football teams beyond traditional outcome statistics.

  • Aggregated dynamic event and phases-of-play data into a single-row-per-(match, team) feature matrix of 40+ attributes across four tactical dimensions
  • Possession phase volumes & durations (build-up, create, finish, quick-break, transition); off-ball run counts by type (in behind, coming short, overlap, pulling wide)
  • Progressive passing structure (forward passes, line-breaking opportunities, passes into the box, total passing distance)
  • Collective pressing behaviour (pressing chain counts and chain lengths)
  • Developed an original "line-breaking opportunity" feature counting pass options capable of bypassing defensive lines — regardless of whether the passer chose to play them
  • Documented results, methodology and next steps — published tutorials across four learning paths with MkDocs Material

Project 09

Fake News Detection — NLP Classification

NLP pipeline classifying news headlines as real or fake, systematically comparing multiple text representations and machine learning classifiers — achieving 92.7% accuracy on a 6,831-sample test set.

  • Full NLP preprocessing pipeline: lowercasing, punctuation removal, tokenization, lemmatization, POS tagging and stopword filtering (NLTK)
  • Generated three distinct feature representations: Bag of Words, TF-IDF and POS-tagged n-grams (bigrams)
  • Trained and benchmarked Random Forest and Multinomial Naive Bayes classifiers across all feature types
  • Best result: Random Forest + TF-IDF — 92.7% accuracy (Precision: 0.934, Recall: 0.914, F1: 0.924)
  • Delivered final predictions on held-out test data with structured presentation of findings
